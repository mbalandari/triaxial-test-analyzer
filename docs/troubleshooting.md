# Troubleshooting Guide

Common issues and solutions.

---

## 1. GUI does not start

Run from project root:

```bash
python -m gui.app
```

---

## 2. "ModuleNotFoundError: No module named 'gui'"

Cause:

Running

- python gui/app.py

Fix:

Run:

```bash
python -m gui.app
```

---

## 3. Empty example files

Use the provided sample files in examples/.
